# EduCode Inclusivo

O EduCode Inclusivo é um portal web interativo criado para ajudar alunos iniciantes a compreender o conceito de algoritmos de forma simples, prática e divertida.

## Tecnologias Utilizadas
* HTML5
* CSS3
* JavaScript

## Funcionalidades e Melhorias Implementadas
Para transformar o projeto inicial num portal mais completo, foram implementadas as seguintes melhorias[cite: 11]:
* **Secção de apresentação:** Adição de uma área para explicar o propósito e os objetivos do projeto[cite: 11].
* **Menu de navegação responsivo:** Barra de navegação que facilita o acesso às diferentes secções da página e se adapta a ecrãs de telemóveis[cite: 11].
* **Modo Escuro (Dark Mode):** Botão de alternância de tema (claro/escuro) para melhorar o conforto visual do utilizador[cite: 11].
* **Quiz Interativo:** Pergunta interativa com validação em tempo real. Inclui feedback visual imediato: a caixa de texto treme caso a resposta esteja errada e são lançados confetes virtuais quando a resposta está correta.

## Como Executar
Não é necessária qualquer instalação complexa. Basta colocar os ficheiros (`index.html`, `style.css` e `script.js`) na mesma pasta e abrir o ficheiro `index.html` em qualquer navegador web.
